Rights Management System (RMS)

A centralized platform designed to capture, organize, and seamlessly manage complex contract details across various media types.

About the Project

The Rights Management System (RMS) is a critical enterprise application built to handle the intricate workflow of contract management. It automates the organization of legal agreements, media rights, and compliance documentation, ensuring that all data is secure, easily accessible, and efficiently tracked throughout its lifecycle.

As a core developer on this project, my focus was on building a resilient backend architecture capable of handling heavy data loads, ensuring data integrity within the database, and providing a seamless API experience for the frontend client.

Key Features & Contributions

  • Database Architecture

    Designed and optimized complex SQL Server tables and stored procedures to handle vast amounts of contract data.

  • Secure File Management

    Integrated Azure Blob Storage (using Azure.Storage.Blobs) to securely upload and retrieve digital contract files and media assets.

  • Backend API Development

    Developed robust endpoints using C# and ASP.NET MVC/Core to serve data securely to the frontend.

  • Issue Resolution & Maintenance

    Actively debugged server-level issues and resolved complex assembly binding conflicts to ensure high system uptime.

Technologies Used
C# ASP.NET MVC .NET Core SQL Server Azure Blob Storage
